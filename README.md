# theCreative Mharvy Portfolio & Platform (mharvy.com.ng Clone)

An authentic, modern, high-performance clone of **[mharvy.com.ng](https://mharvy.com.ng)**, the official website and digital ecosystem of **Chibuike Godwin Marvellous** (*theCreative Mharvy*)—Nigerian visual communications designer, brand strategist, tech entrepreneur, and youth advocate.

Built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**.

## 🛠️ Getting Started

### 1. Prerequisites
Ensure you have Node.js 18+ installed on your system.

### 2. Development Server
Run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view the site.

### 3. Production Build
Build and optimize the application:
```bash
npm run build
npm start
```
